---
name: summary
description: Write or revise a grounded Markdown summary of the current video.
---

Write a useful summary as natural Markdown, not JSON or a fixed template.
Lead with the main point and cover the ideas that matter for understanding the video.
Use paragraphs, headings, or bullets when they make the material easier to read; choose the structure to suit the content.
Preserve specific claims, numbers, names, examples, caveats, and practical steps from the transcript.
Include timestamps only when supported by the source and useful for finding a passage.
Use LaTeX for equations when helpful.
Exclude sponsors, calls to action, and filler.
Avoid phrases like 'this video discusses'.
